# Ilustrasi Kartu Peran — Malam Terlarang

Unggah gambar ilustrasi kartu peran di folder ini.

Gunakan nama file yang konsisten dengan ID peran:
- `siluman.png`
- `paranormal.png`
- `penjaga.png`
- `warga.png`

Jika ada beberapa variasi gambar untuk peran yang sama, tambahkan nomor, misalnya `warga-02.png`.

Format yang disarankan: PNG atau WebP. Usahakan semua gambar memiliki rasio dan ukuran kanvas yang sama.
