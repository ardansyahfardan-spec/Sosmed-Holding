# Arena Gaib — Status Pemain

Simpan aset status pemain di folder ini:

- `hidup.png` — indikator pemain yang masih hidup.
- `mati.png` — pengganti foto profil pemain yang sudah tereliminasi.

Gunakan nama file tersebut agar mudah dipanggil dari tampilan game. Aset gambar akan ditambahkan setelah file dikirim.
