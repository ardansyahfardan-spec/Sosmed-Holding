GHOUSSTORY CONTROL ROOM — V1
================================

Cara menjalankan:
1. Ekstrak ZIP ini ke satu folder.
2. Pastikan index.html, ghoustory-logo.png, dan ghoustory-banner.jpg berada dalam folder yang sama.
3. Buka index.html menggunakan Chrome atau Microsoft Edge.

Yang tersedia:
- Dashboard contoh
- Form persiapan Multi Upload
- Caption Manager berbasis template (belum AI sungguhan)
- Analytics dan ranking dengan angka DEMO
- Riwayat draft lokal 7 hari

Catatan penting:
- V1 ini masih prototype frontend.
- Belum terhubung ke akun Facebook, TikTok, atau YouTube.
- Belum melakukan upload/publikasi otomatis.
- Angka analytics hanya data contoh, bukan data channel asli.
- Gemini AI belum terhubung. Integrasi API akan menjadi tahap berikutnya dan tunduk pada kuota/ketentuan Google.
- Draft disimpan di browser/perangkat yang digunakan.
